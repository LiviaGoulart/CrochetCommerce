# 🧶🎀 CrochetCommerce

> Uma plataforma SaaS criada para unir **crochê, tecnologia e criatividade**. 💗

## ✨ Objetivo

O **CrochetCommerce** tem como objetivo oferecer uma plataforma para a divulgação e comercialização de produtos de crochê, facilitando a organização dos produtos e proporcionando uma experiência agradável para clientes e crocheteiras.

## 💻 Tecnologias

- 🌸 HTML5
- 🎀 CSS3
- 💗 JavaScript
- 🐘 PHP
- 🗄️ MySQL
- 🔌 API REST

## 🌷 Funcionalidades

- Cadastro e login de clientes e crocheteiras.
- Acesso à conta do cliente somente após realizar o login.
- Perfil do cliente com foto, informações pessoais e edição de dados.
- Visualização e acompanhamento de pedidos.
- Área de produtos favoritos.
- Cadastro, edição e gerenciamento de produtos pelas crocheteiras.
- Upload de fotos de perfil e produtos.
- Integração com banco de dados.
